**A lightweight, practical Tailwind CSS plugin for hiding scrollbars while preserving scrolling functionality**

![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-v4.0+-38bdf8?style=flat&logo=tailwindcss)
![Version](https://img.shields.io/npm/v/tailwind-plugin-no-scrollbar)
![License](https://img.shields.io/npm/l/tailwind-plugin-no-scrollbar)

## ✨ Features
- 🎨 Tailwind v4.x
- 📦 Zero dependencies

## 🚀 Usage

```bash
@plugin "tailwind-plugin-no-scrollbar"
# or
@import "tailwind-plugin-no-scrollbar/v4"
```

## 📦 Installation

```bash
npm install tailwind-plugin-no-scrollbar
# or
yarn add tailwind-plugin-no-scrollbar
# or
pnpm add tailwind-plugin-no-scrollbar
```
